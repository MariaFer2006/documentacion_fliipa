### CU-017: Administrar y consultar clientes en blacklist

![Diagrama de caso de uso CU-017](imagenes/diagrama_CU-017.svg)

| Campo | Detalle |
|---|---|
| **Actores** | Administrador del producto |
| **Descripción** | *(Parcial — ver Estado en plataforma.)* El administrador agrega o retira clientes de la lista negra (blacklist) a nivel de servicio. Hoy esto no bloquea de forma efectiva al cliente en checkout, evaluación de riesgo o desembolso, y el listado completo consultable en el panel (con motivo) aún no existe (HU-035 pendiente). |
| **Precondiciones** | Existe evidencia o decisión de negocio para incluir o retirar a un cliente de la blacklist. |
| **Flujo principal** | 1. El administrador busca al cliente a incluir o retirar de la blacklist.<br>2. El sistema valida que el cliente exista.<br>3. El administrador registra el motivo por el cual el cliente ingresa a la lista negra (o el motivo de retiro) — *pendiente confirmar si esto está garantizado hoy en el modelo (ver Reglas de negocio)*.<br>4. El sistema agrega o retira al cliente de la blacklist a nivel de servicio.<br>5. *(No disponible hoy)* El administrador consultaría, desde el panel, el listado completo de clientes en blacklist con su motivo; esta pantalla está pendiente de implementar. |
| **Flujos alternativos / excepciones** | A1. El cliente no existe: el sistema no permite la operación.<br>A2. El administrador no tiene permisos suficientes: no puede gestionar ingresos o salidas, solo consultar (según el nivel de permiso), cuando exista esa consulta. |
| **Postcondiciones** | El cliente queda incluido o retirado de la blacklist a nivel de servicio. Esto no implica bloqueo efectivo en checkout, evaluación o desembolso, ni que el listado completo esté disponible para consulta en el panel: esa parte está pendiente. |
| **Reglas de negocio** | Se busca que todo ingreso a blacklist registre un motivo, pero hoy esto no está garantizado en el modelo de datos: hay que decidir si se implementa esa garantía o se ajusta la regla para reflejar lo que el sistema realmente exige. La consulta y gestión del listado completo requerirá permisos administrativos una vez esté implementada. |
