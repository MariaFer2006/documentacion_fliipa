### CU-029: Entrar como cliente para soporte (impersonación)

![Diagrama de caso de uso CU-029](imagenes/diagrama_CU-029.svg)

| Campo | Detalle |
|---|---|
| **Actores** | Administrador con permiso `product:impersonate-client` |
| **Descripción** | El administrador inicia sesión en el portal del cliente (redemption) en representación de un cliente empresarial específico, sin necesidad de conocer su PIN, para brindarle soporte o verificar lo que el cliente ve en su propia sesión. |
| **Precondiciones** | El administrador tiene el permiso `product:impersonate-client` (rol Sys Admin o Product Admin). El cliente a impersonar tiene una línea de crédito en estado Aprobado o Activa. |
| **Flujo principal** | 1. El administrador solicita impersonar a un cliente específico desde el panel.<br>2. El sistema (admin) solicita internamente a `b2b` un token de intercambio para ese cliente.<br>3. `b2b` valida que el estado de la línea de crédito del cliente sea Aprobado o Activo.<br>4. `b2b` emite un token de intercambio de un solo propósito, válido por 60 segundos.<br>5. El sistema redirige al administrador al portal del cliente (redemption) con ese token.<br>6. Redemption intercambia el token por una sesión de cliente real, válida por 10 minutos y marcada como impersonada (incluye el correo y nombre del administrador).<br>7. El sistema registra la impersonación en el log de auditoría del panel. |
| **Flujos alternativos / excepciones** | A1. El cliente no tiene una línea de crédito Aprobada o Activa: la solicitud de impersonación se rechaza antes de emitir el token.<br>A2. El token de intercambio expira (más de 60 segundos) o ya fue usado: el intercambio por sesión falla.<br>A3. La solicitud de impersonación falla por cualquier motivo: el intento queda igualmente registrado en el log de auditoría. |
| **Postcondiciones** | El administrador queda con una sesión activa en el portal del cliente, limitada en el tiempo y marcada como impersonada; la acción queda registrada en el log de auditoría del panel. |
| **Reglas de negocio** | Solo se puede impersonar a clientes con línea de crédito Aprobada o Activa. El token de intercambio es de un solo propósito y de vida muy corta (60 segundos); la sesión resultante (10 minutos) es más corta que una sesión normal de cliente. |
