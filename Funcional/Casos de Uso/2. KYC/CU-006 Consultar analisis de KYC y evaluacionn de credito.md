### CU-006: Consultar análisis de KYC y evaluación de crédito

![Diagrama de caso de uso CU-006](imagenes/diagrama_CU-006.svg)

| Campo | Detalle |
|---|---|
| **Actores** | Analista de riesgo; Administrador / operaciones (secundario, para HU-038/039) |
| **Descripción** | El analista consulta centrales (Experian: Reconocer y Advance Score) y las coincidencias entre los datos de contacto del cliente y lo reportado en Reconocer, como apoyo para revisar la solicitud; el histórico transaccional de D1 y el score no vienen en esa misma vista, se consultan por separado. |
| **Precondiciones** | El cliente cuenta con una solicitud en evaluación y con información consultable en centrales. |
| **Flujo principal** | 1. El analista abre la ficha del cliente.<br>2. El analista consulta el resultado de Experian (Reconocer y Advance Score).<br>3. El sistema muestra si los datos de contacto (correo, celulares, direcciones) del cliente o su representante legal coinciden con los reportados en Reconocer, resaltando las coincidencias.<br>4. El analista revisa si paso las reglas dura de originación de colpatria. <br> 5.El analista verifica que el cupo calculado sea mayor a 0 o a la base estipulada por colpatria. <br>6. Si el analista necesita el histórico transaccional D1 o el score, los consulta por separado, ya que no aparecen en esta misma vista. |
| **Flujos alternativos / excepciones** | A1. El dato de Fliipa no aparece en centrales: el sistema lo indica explícitamente.<br>A2. No hay dato en Fliipa para comparar: se muestra "sin dato en registro".<br>A3. La sección no trae información de centrales: se muestra sin datos.<br>A4. El analista solicita actualización de un producto de centrales cuando aplique.<br>A5. Las reglas duras de colpatria resultan en rechazo. <br> 6.No se obtiene un cupo preaprobado valido de acuerdo con la base de colpatria   |
| **Postcondiciones** | El analista cuenta con la información de centrales consultada (y, si la buscó por separado, del histórico D1 y el score) para revisar la solicitud. Este CU no produce por sí mismo una decisión de crédito. |
| **Reglas de negocio** | Esta consulta es asistencia visual al analista; no reemplaza ni sustituye la decisión automática del motor KYC (ver [CU-020](CU-020%20Motor%20KYC%20automatico%20post-solicitud.md)), que es quien aprueba o rechaza el crédito. |
