# HU-004: Confirmar canales de contacto

|            Campo            |                                                                                                                                                                                                                                              Detalle                                                                                                                                                                                                                                              |
| :-------------------------: | :-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------: |
|          **Actor**          |                                                                                                                                                                                                                                        Cliente empresarial                                                                                                                                                                                                                                        |
|         **Historia**        |                                                                                                                                               Como cliente empresarial, quiero confirmar mis canales de contacto registrados, para asegurar que la información utilizada para las comunicaciones y el envío de códigos de verificación sea correcta.                                                                                                                                              |
|        **Prioridad**        |                                                                                                                                                                                                                                                Alta                                                                                                                                                                                                                                               |
| **Criterios de aceptación** | El sistema debe mostrar al cliente los canales de contacto registrados disponibles para el proceso de vinculación. El cliente debe poder confirmar que la información mostrada es correcta antes de continuar con el flujo. Si el cliente identifica información incorrecta, debe poder regresar al paso correspondiente para corregir sus datos de contacto. Una vez confirmados los canales, el sistema debe utilizarlos para las siguientes comunicaciones y procesos de validación definidos. |
|        **Relaciones**       |                             Casos de uso: [CU-003](../../Casos%20de%20Uso/1.%20Onboarding/CU-003%20Confirmar%20identidad%20mediante%20OTP.md). Requerimiento: [RF-006](../../Requerimientos/Requerimientos%20Funcionales.md).
