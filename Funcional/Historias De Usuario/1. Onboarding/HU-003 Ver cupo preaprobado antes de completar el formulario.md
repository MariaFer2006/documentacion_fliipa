# HU-003: Consultar cupo preaprobado

|            Campo            | Detalle                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| :-------------------------: | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
|          **Actor**          | Cliente empresarial                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
|         **Historia**        | Como cliente empresarial, quiero consultar el cupo preaprobado asociado a mi documento de identificación, para conocer el monto disponible antes de continuar con el proceso de onboarding.                                                                                                                                                                                                                                                                                                                                           |
|        **Prioridad**        | Alta                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| **Criterios de aceptación** | 1. Una vez identificado el cliente y validada la existencia de una preaprobación, el sistema muestra el valor del cupo preaprobado.<br>2. El cupo se muestra antes de solicitar al cliente completar los pasos posteriores del onboarding.<br>3. El valor mostrado corresponde al cupo sugerido o preaprobado registrado para el cliente en la información procesada por la plataforma.<br>4. Si el cliente no tiene un cupo preaprobado disponible, el sistema debe continuar con el flujo definido para clientes sin preaprobación. |
|        **Relaciones**       | Casos de uso: CU-002. Requerimiento: RF-005. Historias relacionadas: [HU-002](../1.%20Onboarding/HU-002%20Consultar%20si%20tengo%20cupo%20preaprobado%20con%20mi%20n%C3%BAmero%20de%20documento.md), [HU-004](../1.%20Onboarding/HU-004%20Confirmar%20identidad.md).                                                                                                                                                                                                                                                                  |

|       **Comentarios**       | **Confirmado en plataforma:** la información de preaprobación y el cupo sugerido se encuentran operativos en el motor de riesgo. La plataforma permite cargar y procesar la información de clientes preaprobados mediante archivo y obtener el cupo sugerido utilizado durante el flujo. Por tanto, esta funcionalidad cuenta con soporte operativo y no corresponde únicamente a una definición documental.                                                                                                                          |
