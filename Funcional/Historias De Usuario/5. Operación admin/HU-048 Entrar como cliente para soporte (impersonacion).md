#### HU-048: Entrar como cliente para soporte (impersonación)

| Campo | Detalle |
|:---:|:---:|
| **Actor** | Administrador con permiso "Entrar como usuario" (`product:impersonate-client`) |
| **Historia** | Como administrador del panel con el permiso correspondiente, quiero entrar al portal del cliente (redemption) como si fuera él, sin conocer su PIN, para poder brindarle soporte y verificar lo que el cliente está viendo en su propia sesión. |
| **Prioridad** | Media |
| **Criterios de aceptación** | El administrador solo puede impersonar a clientes cuya línea de crédito esté en estado Aprobado o Activa; si el cliente no cumple esta condición, la solicitud es rechazada. Al iniciar la impersonación, el sistema genera un enlace de acceso al portal del cliente válido por un tiempo corto (60 segundos) y de un solo propósito. Al usar ese enlace, se abre una sesión en el portal del cliente marcada explícitamente como impersonada, indicando qué administrador la originó, con una duración más corta que una sesión normal (10 minutos). Toda impersonación, exitosa o fallida, queda registrada en el log de auditoría del panel administrativo con el identificador del cliente afectado. |
