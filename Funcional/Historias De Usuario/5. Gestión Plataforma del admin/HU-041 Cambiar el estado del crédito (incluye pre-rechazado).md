###  HU-041 — Cambiar el estado del crédito (incluye pre-rechazado)

| Campo | Detalle |
| --- | --- |
| **Actor** | Administrador / analista de riesgo |
| **Historia** | Como administrador, quiero cambiar el estado de la línea de crédito del cliente (incluido pre-rejected), para gestionar casos en evaluación o decisión manual. |
| **Prioridad** | Alta |
| **Criterios de aceptación** | Desde la ficha, con permiso, se puede cambiar el estado. Existe el estado **pre-rejected**. Al pasarlo a pre-rechazado, el equipo recibe una alerta operativa. El cliente no reentra al flujo de forma inconsistente con ese estado. |
| **Relaciones** | HU-008 (resultado de la solicitud); HU-044 (decisión **automática** del KYC — distinta de esta). |

| **Fecha** | 18/08/2026 |

| **Estado en plataforma** | **Hecho** (cambio **manual**). |
